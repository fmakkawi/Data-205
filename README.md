## 📊 Project Overview
This project analyzes the relationship between income, education, and internet access across Maryland counties. The goal is to understand how these factors are connected and how they differ between regions, with a focus on Montgomery County and Prince George’s County.

## 📁 Data Sources
- U.S. Census Bureau (data.census.gov)
- Maryland Open Data

The dataset includes all 24 Maryland counties and contains:
- Median income  
- Population  
- Bachelor's degree percentage  
- Internet access percentage  

## 🔍 Methods Used
- Data cleaning and merging  
- Exploratory Data Analysis (EDA)  
- County grouping by region  
- ANOVA (statistical testing)  
- Correlation analysis  
- Linear regression  
- Data visualization (boxplots, bar charts, scatter plots)  

## 📈 Key Findings
- There are statistically significant differences in income across Maryland regions.  
- Income is strongly positively correlated with education and internet access.  
- Internet access shows the strongest relationship with income.  
- Regression results indicate that education and internet access explain over 80% of income variation.
