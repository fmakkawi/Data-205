## 📊 Project Overview  
This project examines income inequality across Maryland counties by analyzing the relationship between median income, educational attainment, and internet access. The analysis began with a comparison between Montgomery County and Prince George’s County, but was expanded to include all 24 Maryland counties to provide a more comprehensive and reliable understanding of regional differences.  

The objective of this project is to identify patterns, measure relationships, and evaluate how key socioeconomic factors contribute to variations in income across the state.

---

## 📁 Data Sources  
The data used in this project was obtained from:  
- U.S. Census Bureau (data.census.gov)  
- Maryland Open Data  

The dataset includes all 24 Maryland counties and contains the following variables:  
- Median household income  
- Population  
- Bachelor’s degree percentage  
- Internet access percentage  

These variables were selected to explore how education and access to technology influence economic outcomes.

---

## 🔍 Methods Used  
The analysis combines both exploratory and statistical methods to better understand the data:

- Data cleaning and merging from multiple sources  
- Exploratory Data Analysis (EDA) using visualizations  
- Grouping counties by region for comparison  
- ANOVA testing to evaluate statistical significance  
- Correlation analysis to measure relationships between variables  
- Linear regression modeling to predict income based on education and internet access  
- Data visualization (boxplots, bar charts, scatter plots)  

This multi-step approach allows for both visual interpretation and statistical validation of findings.

---

## 📈 Key Findings  
- There are statistically significant differences in income across Maryland regions.  
- Income is strongly positively correlated with educational attainment (≈ 0.78).  
- Internet access has an even stronger relationship with income (≈ 0.87).  
- Regression analysis shows that education and internet access explain over 80% of income variation (R² ≈ 0.82).  
- Regional location, education, and access to technology are key drivers of income differences.
